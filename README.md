# גיבורי העיר

משחק לבר ולירדן (בני 5): יוצאים למשימות קצרות כדי להציל את העיר, וכל משימה שמצליחה
נותנת חלק חדש לבסיס הגיבורים או כוח מיוחד.

## איך פותחים
לוחצים פעמיים על `index.html`. הכי טוב ב־**Microsoft Edge** (שם הקול בעברית הכי טבעי).
המשחק מדבר, כי ילדים בני 5 עוד לא קוראים הוראות: כפתור 🔊 משמיע שוב.

## ארבעה מקומות בעיר
- 📚 **ספריית האותיות**: למצוא אות לפי השם שלה, באיזו אות מתחילה מילה, איזו אות חסרה במילה.
- 🪧 **פארק השלטים** (קריאה): לקרוא מילה עם ניקוד ולבחור תמונה, לבחור מילה לתמונה.
- ✏️ **סדנת הכתיבה**: להרכיב מילה מאותיות, להקליד מילה במקלדת, לעקוב עם העכבר אחרי צורת אות.
- 🤖 **גשר הרובוטים** (מספרים): לספור, להשלים רצף, חיבור וחיסור עד 10. כל תשובה נכונה מרדימה את הרובוט קצת.

כל משימה = 5 אתגרים. אחרי 3 משימות באותו מקום השלב עולה (עד 3).
פרסים: שני חלקים לבסיס, ואז כוח מיוחד (שרואים על הגיבור), וחוזר חלילה.

## איפה נשמרת ההתקדמות
בדפדפן, במחשב הזה (לכל ילד בנפרד). ב"פינת ההורים" רואים התקדמות ואפשר לאפס.

## לשנות תוכן
- מילים, אותיות, פרסים וצבעי הגיבורים: `js/data.js`
- האתגרים: `js/challenges.js`
- המסכים: `js/app.js`, ציורים: `js/art.js`
